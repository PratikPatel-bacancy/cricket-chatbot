# Scoring System

## Points within a game

Points are called, in order: **love** (0), **15**, **30**, **40**, and then **game** if a player
leads by at least 2 points. If both players reach 40, it's called **deuce**; from deuce, a player
must win two points in a row to win the game — winning the first point after deuce gives that
player "advantage," and winning the next point wins the game, while losing it returns the score to
deuce.

## Games and sets

A set is won by the first player to win 6 games, provided they lead by at least 2 games (e.g. 6–4).
If the set reaches 6 games each (6–6), a **tiebreak** is usually played (rules vary by tournament
for the deciding set — some still play advantage sets requiring a 2-game lead with no tiebreak).

## The tiebreak

Played to determine the winner of a set tied at 6-6 (in most cases). Players alternate serves,
typically serving one point first, then alternating every two points, and score is counted in
simple numbers (1, 2, 3...) rather than love/15/30/40. The first player to reach 7 points with at
least a 2-point lead wins the tiebreak (and the set); if not, play continues until one player leads
by 2.

## Match format

Matches are typically best-of-3 sets (first to win 2 sets) in most professional tour-level and
WTA/ATP matches, or best-of-5 sets (first to win 3 sets) in the men's singles at Grand Slam
tournaments.

## Faults and double faults

A serve is a **fault** if it lands outside the correct service box, or if the server foot-faults
(illegally stepping on or over the baseline before striking the ball). A server gets two attempts
per point; missing both is a **double fault**, which awards the point to the receiver.
